CineVerse

Website Planning Document

1. Site Name

CineVerse

This name represents a complete cinematic universe of information. It connects "cinema" (representing films, features, and movie stories) with "universe," reflecting a portal where fans can search, explore, and track movies. It is catchy, modern, and easily hints at the site's focus.

Optional domain availability: cineverse-app.io

2. Site Purpose

CineVerse is a movie database and organization tool for film enthusiasts. The site provides:

  • A dynamic Movie Explorer utilizing TMDB API integration to search and discover popular, high-rated, or trending films.
  • Comprehensive movie details (posters, descriptions, ratings, and classifications).
  • A personalized Watchlist Tracker where users can add and delete titles, saved persistently to their browser's local storage.

3. Scenarios

  • What are the most popular movies streaming right now according to user scores?
  • Where can I search for detailed posters and summaries of a specific movie title?
  • How do I save a custom movie log to my personal queue to track what I plan to watch next?

4. Color Schema

The color schema uses a dark space gaming/cyberpunk background with neon accents to reflect clean visual energy and contrast.

  • Deep Space Navy (#12121a) — used as the main page background.
  • Neon Violet (#8b5cf6) — used for headings and navigation highlights.
  • Cyber Cyan (#22d3ee) — used for links, buttons, and accents.
  • Soft White (#f4f4f8) — used for body text for high readability.

5. Typography

Two fonts from Google Fonts were selected:

  • Orbitron — a bold, futuristic display font used for all headings and navigation, matching the technology/cyber aesthetic.
  • Poppins — a clean, modern sans-serif used for body text, lists, and general content for comfortable reading.
